# Sound source for Kaos Arena 3D (staging)

File: `public/audio/pistol-fire.wav`

- **Recording:** processed pistol-like report derived from a real 20-gauge shotgun shot recorded by **michorvath**, as documented by the source project. This is **not** claimed to be an actual pistol recording.
- **Original source:** Freesound recording by michorvath, used under Creative Commons Zero (CC0 1.0).
- **Processed file:** `system-prompt-pistol.wav` from https://github.com/transitive-bullshit/ai-safety-doom/tree/main/public/game/audio
- **Source documentation:** https://github.com/transitive-bullshit/ai-safety-doom/blob/main/public/game/audio/README.md
- **Declared license for this particular file:** Creative Commons Zero (CC0 1.0); commercial game reuse allowed without attribution.
- **Local file format:** WAV, mono 44.1 kHz, approximately 0.31 seconds.
- **Playback:** Web Audio, slight randomized playback rate, independent mute control; procedural noise fallback only if loading/decoding fails.

The processed source was chosen for its short game-friendly attack. It is **not** a sound from Doom and is independent of the copyrighted Doom samples found elsewhere in the source project's repository.

The sound file is bundled in this independent Kaos Arena repository.
