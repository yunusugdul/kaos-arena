# 3D soldier model

The bundled Soldier.glb is the **Mixamo** model used by the official Three.js skeletal animation example.

- Pinned source: https://github.com/mrdoob/three.js/blob/r181/examples/models/gltf/Soldier.glb
- Official example and model attribution: https://threejs.org/examples/webgl_animation_skinning_blending.html
- Model provider: https://www.mixamo.com/
- Three.js code: MIT. Model content has its provider's usage terms; the code license does not replace those terms. This project uses the character as an embedded game asset, not a standalone model product.

The supplied reference images guide the environment, uniform colors and proportions. This is not a claim that their exact characters were reconstructed. The courtyard geometry, textures and fallback soldiers are generated by this project. No model is downloaded at game startup.
